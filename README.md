# Movie Data Analysis (EDA)

## Project Overview
This project explores movie data using Exploratory Data Analysis (EDA) to understand genre distribution, movie popularity, audience ratings, and release-year trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and preprocessing
- Handling missing values and duplicate records
- Converting data types and extracting release years
- Categorizing vote averages using quantiles
- Analyzing movie genres and their distribution
- Exploring movie popularity and release-year trends
- Creating visualizations to identify patterns in the dataset

## Project Files
- `Top_Movies_EDA.ipynb` — notebook containing the analysis and visualizations
- `Top Movies dataset.csv` — dataset used for the analysis

## Objective
To strengthen my practical skills in data cleaning, data manipulation, exploratory analysis, and data visualization using Python.
